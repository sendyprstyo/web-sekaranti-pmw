# 1. PROJECT OVERVIEW

## 1.1 Tentang Proyek

SEKARANTI merupakan brand fashion yang bergerak di bidang penjualan hijab premium printing dengan karakteristik motif yang elegan, artistik, dan memiliki identitas tersendiri.

Website SEKARANTI dikembangkan sebagai platform informasi resmi brand untuk memperkenalkan identitas bisnis, menampilkan berbagai koleksi hijab, memberikan informasi detail produk, serta mengarahkan pelanggan ke platform e-commerce resmi.

Website ini berfungsi sebagai digital brand showroom yang memberikan pengalaman visual premium kepada pengunjung.

## 1.2 Tujuan Website

1. Memperkenalkan brand SEKARANTI kepada masyarakat.
2. Menampilkan seluruh koleksi hijab yang tersedia.
3. Memberikan informasi detail dan filosofi setiap koleksi.
4. Menyediakan katalog produk yang mudah dijelajahi.
5. Mengarahkan pelanggan ke Shopee, Tokopedia, dan TikTok Shop.
6. Menyediakan layanan pemesanan COD khusus wilayah Kota Semarang melalui WhatsApp.
7. Meningkatkan kepercayaan pelanggan terhadap brand SEKARANTI.

## 1.3 Konsep Website

Website menggunakan pendekatan:

**Premium, Elegant, Feminine, Modern, dan Minimalist.**

Fokus utama website adalah fotografi produk hijab. Ketika pengunjung membuka website, mereka harus langsung disambut dengan tampilan koleksi hijab SEKARANTI, bukan halaman yang dipenuhi teks atau informasi yang terlalu panjang.

# 7. COD ORDER SYSTEM

SEKARANTI menyediakan metode pemesanan Cash on Delivery (COD) khusus wilayah Kota Semarang.

### Mekanisme

1. Pengunjung membuka halaman produk.
2. Pengunjung memilih tombol Order via WhatsApp.
3. Website membuka WhatsApp.
4. Sistem menyiapkan pesan otomatis berisi nama produk dan tautan produk.
5. Pelanggan melanjutkan konfirmasi pesanan dengan admin.

**WhatsApp resmi:**

085727033141

Format pesan otomatis:

"Halo SEKARANTI, saya tertarik untuk memesan produk [Nama Produk]. Apakah tersedia untuk pemesanan COD wilayah Semarang?"

Ketentuan:
- COD hanya diinformasikan untuk wilayah Kota Semarang.
- Konfirmasi ketersediaan dan pengiriman dilakukan melalui WhatsApp.
- Website tidak memproses pembayaran atau menyimpan transaksi.

# 10. ASSET MANAGEMENT

Seluruh foto produk akan diberikan dalam satu folder bernama:

`assets/`

Dokumen PDF koleksi akan diberikan secara terpisah.

Struktur aset yang direkomendasikan:

```text
public/
└── assets/
    ├── logo/
    │   └── sekaranti-logo.png
    ├── hero/
    │   └── hero-image.jpg
    ├── collections/
    │   ├── collection-01/
    │   ├── collection-02/
    │   ├── collection-03/
    │   └── collection-04/
    ├── products/
    │   ├── product-01/
    │   ├── product-02/
    │   └── ...
    └── gallery/
```

Ketentuan pengelolaan aset:

- Gunakan foto asli yang disediakan.
- Jangan mengganti foto produk dengan gambar AI.
- Jangan menggunakan foto produk yang tidak berkaitan dengan SEKARANTI.
- Jangan mengubah motif, warna, atau karakteristik hijab.
- Gunakan optimasi gambar tanpa mengurangi kualitas visual secara berlebihan.
- Pastikan setiap produk memiliki hubungan yang jelas dengan koleksinya.

# 11. TECHNICAL REQUIREMENTS

Website merupakan website informasi statis yang tidak membutuhkan sistem transaksi internal.

Rekomendasi teknologi:

- Frontend: React / Next.js.
- Styling: Tailwind CSS.
- Animation: Framer Motion.
- Icons: Lucide Icons.
- Deployment: Vercel.
- Assets: Local static assets.

Teknologi akhir dapat menyesuaikan infrastruktur proyek yang sudah tersedia.

### Database

Untuk tahap pertama:
- Tidak membutuhkan database.
- Data produk dapat disimpan dalam file JSON.
- Data koleksi dapat dikelola melalui file konfigurasi.
- Link marketplace disimpan bersama data produk.
- Seluruh foto menggunakan local assets.

Contoh struktur data produk:

```json
{
  "id": "product-001",
  "name": "Nama Produk",
  "collection": "collection-01",
  "description": "Deskripsi produk",
  "images": [
    "/assets/products/product-01/image-1.jpg"
  ],
  "marketplaces": {
    "shopee": "",
    "tokopedia": "",
    "tiktok": ""
  }
}
```
